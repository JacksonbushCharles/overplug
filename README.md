EchoMail sends campaigns through this server-side flow:

`page.tsx → EmailEngine → /api/send → Nodemailer → Resend SMTP`

SMTP credentials are read only by the route handler from `.env.local`; the browser never receives them.

## Resend setup

1. Copy `.env.example` to `.env.local`.
2. Replace `SMTP_PASS` with your Resend SMTP API key and set the sender/reply-to addresses to domains verified in Resend.
3. Start the app with `npm run dev`.
